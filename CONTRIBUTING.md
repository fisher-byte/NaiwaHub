# Contributing / 贡献说明

Please use an issue or pull request for a new public source, factual correction or clearer attribution. Include the affected stable ID where one exists. Series and storyline labels are community classifications, not official canon.

新增公开来源、事实更正或署名补充，请通过 issue 或 pull request 提交，并在适用时注明已有永久 ID。系列和故事线是社区整理，不代表官方设定。

1. Provide an accessible public source and explain what it establishes. A repository owner or commit author is not automatically the image creator. Preserve `creator: null` and unknown rights when evidence is missing.
2. Provide the original file, full SHA-256, format and any source license or attribution notice. Keep watermarks and embedded credits. Do not crop, enlarge, transcode or split frames to increase the count of works.
3. Supply a factual English and Chinese title, tags and description. Do not invent popularity, release dates, authorship, official relationships or commercial permissions.
4. Do not submit private chat records, contacts, identity documents, secrets, authenticated CDN links, pending UGC, private complaints or full video transcripts. Do not put private evidence in a public issue or pull request.
5. Keep stable IDs unchanged. Duplicates use the existing ID with additional verified sources. Reclassification can change the series folder; the ID and full-file hash remain the reference.
6. Source licenses keep their original scope. Do not apply this archive's documentation or tooling license to third-party media. No exclusive permission or transfer of ownership is requested.

请提供可核对的公开来源、原件及完整 SHA-256，保留水印与署名；不能把仓库所有者当作图片作者，不能用拆帧或转换制造新增作品。未知作者和权利继续保留未知，不添加没有依据的“官方”“原创”“可商用”结论。不要提交私人聊天、联系方式、证件、密钥、鉴权链接、待审 UGC、私有投诉或视频完整转录。

The maintainer manually checks the source, deduplication, classification and public/private boundary before merging. A contribution is not proof that third-party rights have been cleared. For a rights or privacy concern, follow `README.md` and use the private site report form when available.

维护者会人工核对来源、去重、分类和公开边界后再决定是否合并。贡献记录不等于第三方权利已确认。版权或隐私请求请按 `README.md` 指引，在网站可用时使用私有投诉表单。
